Privacy Policy

Z Tabs is a browser extension that lets Zalo Web (https://chat.zalo.me) run in several browser tabs that share one connection.

What the extension handles

To do this, Z Tabs relays Zalo Web’s own connection traffic between your open Zalo Web tabs, and that traffic can include chat messages. This happens entirely inside your browser. To deliver each reply to the tab that asked for it, Z Tabs may decode a reply only to read its request identifier.

What it does not do

Z Tabs does not collect, store, log, sell or transmit any message content or personal data. It sends nothing to the developer or to any third party, contains no analytics, and loads no remote code. It runs only on https://chat.zalo.me/ and only while you have it turned on.

Stored settings

Two on/off settings (multi-tab mode and auto-reload) are saved locally with the browser’s extension storage. Uninstalling the extension removes them.

Permissions

  • storage: to save the two settings above.
  • scripting: to switch the bundled content script on and off for chat.zalo.me.
  • https://chat.zalo.me/*: the only site the extension works on.
